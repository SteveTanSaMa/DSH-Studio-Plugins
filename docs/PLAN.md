# 初步验证计划（2026-10-23）

目标：验证独立维护、精确版本、可审查的官方 format 1 插件索引。仓库保持私有。

1. 建立候选清单、精确发布包身份与兼容声明；真实插件目前仅作为技术测试候选。
2. 下载发布包并校验 SHA-512、包名、版本、bundle patch 路径，生成索引与检查证据；不执行第三方代码。
3. 使用官方 parseMarketIndex 校验；失败不得覆盖上次成功产物，下架记录优先于候选清单。
4. 在临时 Profile 启动真实 Harness 服务，验证 HTTP 读取、双语搜索、精确安装参数、缓存/刷新、重定向拒绝、源持久化与移除。
5. 使用本地产生的无依赖测试 bundle，验证官方 Plugin Manager 的安装和卸载；与真实候选功能测试分开。
6. 配置私有 GitHub Actions，推送并检查远程结果；生成初步报告。

本轮不公开部署、不更改用户 Profile、不自动安装社区插件，不接入 App 默认源。
正式发布前：真实插件 UI/功能验证、macOS arm64/x64 验证、无重定向公网 HTTPS 与网络可达性、推荐内容审核。
