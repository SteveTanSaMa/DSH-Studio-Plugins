# 索引发布一致性检查（2026-10-28）

GitHub Raw 直接提供 main 中提交的 `public/index.json`。此前 CI 先重新生成索引再检查，因此即使提交了清单但忘记提交更新后的公开文件，CI 也可能通过。现在 CI 先检查并保留提交中的文件，再生成并逐项比较；只有每次生成的 `checkedAt` 允许不同。

候选说明中的验收结论现由对应包名、版本、SHA-512、Harness 版本和实际检查结果生成。更新版本或摘要后，旧版结论不会继续出现在新条目上；实际功能和 macOS x64 验收仍待完成。

快照现在包含版本验证记录。恢复时合并当前和快照证据，以当前下架记录为准，并根据合并结果重生成索引说明；兼容旧快照中的固定说明和旧索引标题。

本地使用 Node 26.12.1 测试：完整单元测试、实际 npm 发布包重建、官方格式校验和真实 Harness 读取 Raw 索引及本地测试包生命周期。GitHub Actions 在提交后复现构建与集成测试。CI 不能阻止绕过 PR 的直接 main 推送，应等待 PR 检查通过后再合并。
